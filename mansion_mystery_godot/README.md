# คฤหาสน์ที่ไม่มีเจ้าของ — ตอนที่ 1

เกมสืบสวน Android แนวนอน สร้างด้วย Godot 4.3

## ลำดับฉาก
- เล่นคลิปเปิดตอนความยาว 4.4 วินาที พร้อมชื่อเกม แล้วเข้าเกมอัตโนมัติหรือแตะ “ข้าม” ได้
- ใช้ภาพคฤหาสน์ยามสนธยาที่บอสส่งเป็นฉากสำรวจ
- แตะกล่องจดหมาย ประตู หน้าต่าง ป้ายบ้านเลขที่ และไก่ เพื่อเก็บเบาะแส 5 จุด
- ไก่ขยับเดิน จิกพื้น และพักเป็นช่วง ๆ

## หน้าจอและไฟล์
- ความละเอียดอ้างอิง 1280 × 720 (16:9) และล็อกหน้าจอ Android แนวนอน
- คลิปเปิดถูกแปลงจาก MP4 เป็น Ogg/Theora 960 × 540 ที่ 24 fps พร้อมเสียงโมโน; ขนาดประมาณ 0.98 MB

## สร้าง APK
GitHub Actions จะสร้าง APK สำหรับ Android ARM64 เมื่อมีการอัปเดตสาขา `mansion-mystery-apk`
